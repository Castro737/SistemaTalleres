# SistemaTalleres

SistemaTalleres es una aplicación desarrollada para apoyar la gestión de información y procesos relacionados con un sistema de talleres.

## Tecnologías utilizadas

- Angular
- TypeScript
- HTML
- CSS
- Node.js / npm

## Estructura del proyecto

- `src/`: código fuente de la aplicación.
- `public/`: archivos públicos y recursos.
- `.vscode/`: configuración del entorno de desarrollo.
- `angular.json`: configuración principal de Angular.
- `package.json`: dependencias y scripts del proyecto.
- `tsconfig.json`: configuración de TypeScript.
- `.gitignore`: archivos y directorios excluidos del control de versiones.

## Requisitos

Para ejecutar el proyecto se requiere:

- Node.js
- npm
- Angular CLI
